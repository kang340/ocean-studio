# Ocean Studio showcase

- Deliverable: 35 seconds, 1920×1080, 30 fps, silent captions for X.
- Audience: ocean/atmospheric data users and open-source developers.
- Identity: ocean blue, calm and precise; the real scientific field colors stay unchanged.
- Colors: stage #061220, panel #08111c, ink #e4eef7, accent #4cc3ef, secondary #a9bccd.
- Fonts: Segoe UI and Microsoft YaHei, local system font declarations.
- Structure: 0–3 introduction, 3–10 globe wind, 10–17 wave swipe, 17–22 observations, 22–29 model/observation matching, 29–35 GitHub CTA.
- Screen captures are real local application output using bundled October 2026 samples, not a live feed. All scientific attribution in the captured UI remains visible.
- Large Chinese headlines, small English scene counters, hard cuts on footage, 0.5-second eased title entrances. No color filter over scientific data, no invented results, no rapid flicker.
- Music: none; intended to work in muted X feeds.
