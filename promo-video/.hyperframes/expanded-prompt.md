# Ocean Studio / a browser for ocean and weather data

Use design.md: #061220 / #08111c / #e4eef7 / #4cc3ef / #a9bccd, Segoe UI and Microsoft YaHei. Calm scientific software demonstration.

Rhythm: hook — explore — compare — locate — validate — hold.

Global: real UI is the evidence layer. Use generous, readable type above each 1600×900 capture, with a separate quiet data-disclosure footer. Captures have no filters. All scenes share cyan rules, scene counters and a slowly filling progress line. The title enters over 0.55 seconds; small metadata follows after 0.15 seconds. No looping runtime effects or live fetches.

1. 0–3s: reveal Ocean Studio and the statement 把海洋与天气，放进同一个地球. Background is an authentic wind globe still; a solid navy text region preserves contrast. Cyan vertical rule grows; name rises 24px, subtitle follows. Cut to the full application frame.
2. 3–10s: 全球风场，动起来. Authentic particles and globe drag show the 3D wind field. The top heading enters, scene counter settles, footer states GFS · 三维地球 · GPU 粒子流. Hard cut to compare.
3. 10–17s: 两个数据源，一眼看出差异. Record the actual wave swipe control dragged across the map, keeping units and A/B labels visible. Heading rises while the map holds its position. Footer reads CMEMS × WAVEWATCH III · 卷帘对比. Hard cut.
4. 17–22s: 从网格场，走向真实观测. Show real OSMC points and platform information. Header remains large; no invented point values. Footer reads 浮标 / Argo · 轨迹 · 质量控制. Hard cut.
5. 22–29s: 让模式与观测，彼此验证. Run the built-in spatial/temporal matching and show returned scatter/statistics. Preserve the values from the actual run. Footer reads 时空匹配 · Bias / RMSE / 相关系数. Hard cut.
6. 29–35s: open-source CTA. Ocean Studio name, repository kang340/ocean-studio, MIT source, and NetCDF / GRIB2 / CSV. Hold the URL at least 4 seconds. Separate source and sample-data licenses; footer notes bundled samples are October 2026 and not live.

Avoid: false real-time claims, DeepSeek attribution from another project, tinted scientific fields, hidden provenance, fake charts, tiny subtitles, flashing effects.
