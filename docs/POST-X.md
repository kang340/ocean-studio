# X 发布文案

把海洋和天气数据，放进同一个可交互的地球。🌏

Ocean Studio 现已开源：3D 风场与粒子流、海浪双源对比、海温剖面、浮标 / Argo 观测，以及模式–观测匹配检验。

自带约 76 MB 真实样例，支持本地 NetCDF / GRIB2 / CSV。

GitHub：https://github.com/kang340/ocean-studio
